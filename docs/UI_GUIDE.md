# UI guide

PR1 shell находится в `frontend/src/App.tsx:L1-L20`, стили и visual tokens — в `frontend/src/styles.css:L1-L1`.

Доступны ровно три глобальных раздела: **Товары**, **Данные**, **Настройки**. По умолчанию активны **Товары**. Активный пункт имеет `aria-current="page"`, клавиатурный focus видим. Empty state не предлагает ещё не реализованные функции.

Planned / Not implemented: product workspace, imports, KPI, benchmark and analytics.
